# 🌍 JanKalyan

JanKalyan is a **multilingual, offline-first mobile app** that helps citizens **discover and apply for government welfare schemes they are actually eligible for** — through guided questions, not complex documents.

> This project focuses on **access, trust, and last-mile usability**, not just listing schemes.

---

## 🚨 Problem

Millions of eligible citizens remain **unenrolled** in welfare schemes because:
- Schemes are hard to understand
- Portals assume digital & language literacy
- Internet access is unreliable
- There is no guidance or trust-building

---

## 💡 Solution

A **guided decision-support app** that:
- Asks simple questions
- Filters schemes based on eligibility
- Works offline for discovery
- Redirects users to **official portals** to apply

---

## ✨ Key Features

- 🌐 **Multilingual UI** (English, Hindi, Marathi, Gujarati)
- 👤 **Guided profile quiz** (visual, low-literacy friendly)
- 🎯 **Eligibility-based scheme filtering**
- ⭐ **Wishlist for eligible schemes**
- 🔒 **Trusted, official scheme data**
- 📶 **Offline-first design** (internet only needed to apply)

---

## 🔁 User Flow

1. Select Language  
2. Answer Simple Profile Questions  
3. View Only Eligible Schemes  
4. Save to Wishlist  
5. Apply via Official Government Portal  

---

## 🎯 Impact

- Converts **eligibility → enrollment**
- Reduces dependence on middlemen
- Improves welfare reach in rural & low-connectivity areas
- Builds trust through transparency

---

## 🧑‍🤝‍🧑 Built For
